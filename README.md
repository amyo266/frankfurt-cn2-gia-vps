## 线路：三网去回程分别怎么走

这是整篇文章里唯一值得逐字看清的部分，也是这条产品线卖得比普通德国 VPS 贵的原因。

- **电信**：去程 CN2 GIA，回程 CN2 GIA
- **联通**：去程 CN2 GIA，回程 CN2 GIA
- **移动**：去程 CMI 直连，回程 CMIN2 精品网

CN2 GIA 走的是电信下一代承载网 AS4809，路由里能看到 59.43 开头的节点。普通德国 VPS 走的是电信 163（AS4134）、联通 AS4837、移动 CMI，白天勉强能用，晚上高峰期拥堵是常态。公开测试数据里，同类普通线路晚高峰从 180ms 抖到 400ms、丢包 15% 的情况并不罕见，这种线路连 SSH 都会出现敲命令等回显的迟滞感。

要注意移动这一路不是 GIA，是 CMI 去、CMIN2 回。CMIN2 属于移动的精品网，比普通 CMI 好，但和电信联通的双程 GIA 不是一个东西。第三方测速记录里出现过移动侧速率偏低的情况（2024 年一次复测提到单线程下载下降、上传约 19Mbps），移动宽带用户下单前建议自己先测。

## 180ms 是什么水平，什么场景无所谓

法兰克福到国内约 **180ms**，这是中欧之间的物理距离决定的，任何优化都压不到亚洲节点的水平。公开测试数据里，非高峰时段下载能跑到 6MB/s 左右，高峰期有波动，但不是断崖式下跌。

180ms 能接受的场景：跨境建站和后台管理、欧洲节点中转、海外 API 对接、流媒体解锁、远程办公、欧洲时区的开发环境、文件同步。这些场景对首屏和吞吐量的敏感度远高于对单次往返延迟的敏感度。

180ms 不能接受的场景：跨国实时对战游戏、任何对 RTT 有硬要求的交互式应用。这类需求应该找亚洲或美西节点，不是法兰克福。买之前想清楚这一点，能省掉一次无法退款的后悔。

**二、流量双向计费。** 上传和下载都计入每月配额。500GB 的套餐，如果业务里有大量上传（备份推送、网盘同步、做种、大文件分发），实际可用额度要按两倍消耗来估，很快会见底。看重下载量的话，选档时把上传侧也算进去。

**三、不保证原生 IP。** 每个套餐含 1 个独立 IPv4，但官方明确说明不保证是原生 IP，介意 IP 归属地的（特定流媒体区域、需要德国本地 IP 的注册场景）得自己先评估，也不能以此为理由退款。有推广文写“原生 IP 可解锁奈飞”，那是宣传口径，官方 Tos 的说法更保守，按保守的来。

**四、只支持支付宝。** 对国内用户是方便，不用折腾外币卡。反过来，只持有信用卡或 PayPal 的人直接被挡在门外，没有第二条路。
